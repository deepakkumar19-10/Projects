# ⚛️ React Practice Dashboard

A beginner-friendly React project created to practice important React concepts through multiple components in a single dashboard.

## 📌 Project Overview

This project contains four main React components:

- 📝 User Form
- 💬 Comments Form
- 🔢 Counter
- 😂 Random Joke Generator

The main purpose of this project is to understand React fundamentals through practical examples.

---

## ✨ Features

### 📝 User Form

A registration form containing:

- Full Name
- Username
- Password
- Submit Button

### 💬 Comments Form

A comment form containing:

- Username
- Remarks
- Rating
- Add Comment Button

### 🔢 Counter

Two independent counters:

- Count X
- Count Y
- `+1` buttons

### 😂 Joke API

Fetches a random joke from an external API.

Displays:

- Joke Setup
- Punchline
- New Joke Button
